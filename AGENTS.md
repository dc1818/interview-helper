# Project guidance

Read DESIGN.md before changing the interface. Preserve the approved Vivid wireframe direction and the simple daily dashboard. Do not reintroduce a sidebar, decorative metrics, fake lessons or generic blue branding.

Preserve localStorage keys, saved progress and existing curriculum behavior. Test completion/reload, review rating, rest days, narrow screens and the study tools after UI changes. This is a static GitHub Pages site with no build step; main pushes deploy through the existing Pages workflow.
