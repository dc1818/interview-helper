How to use each block

The rules that make the hours count

01 · CLOSED BOOK FIRST

Attempt the problem or explanation before opening notes. Retrieval is the part that prepares you for interviews.

02 · SAY IT OUT LOUD

End concept work with a 60–90 second spoken answer: definition, mechanism, tradeoff, example.

03 · KEEP AN ERROR LOG

Record the mistake, why it happened, and the recognition cue that should trigger the right approach next time.

04 · BUILD EVIDENCE

Turn one study block each week into a commit, test, diagram, README note, or measurable project improvement.

Role-specific emphasis

Use one core, then lean toward the job

The base plan prepares you broadly. When an interview is scheduled, use these swaps for the final seven days instead of adding more hours.

Software / Full-stack / Backend

  • Replace one SQL block with JSDen or Full Stack Open.
  • Prioritize APIs, HTTP, async behavior, databases, caching, and testing.
  • Use JavaScript for one coding problem every fourth Saturday.

Data Engineering / Data Developer

  • Keep both DataLemur blocks and the Zoomcamp project block.
  • Prioritize SQL, modeling, ETL, orchestration, Docker, and pipeline failure modes.
  • Explain data quality and idempotency using project examples.

QA Automation / SDET

  • Replace one Zoomcamp block with Playwright or pytest practice.
  • Prioritize test layers, selectors, fixtures, mocking, CI, and debugging.
  • Turn a personal project workflow into an automated regression test.

Data Analyst + Programming

  • Keep SQL, Python, pandas, and the explanation drills.
  • Replace system-design depth with metric definition and stakeholder questions.
  • Practice explaining how a result changes a decision.

Timed coding screen

  • Use Python unless the employer requires another language.
  • Narrate assumptions, complexity, tests, and edge cases.
  • Stop after the time limit and review the decision process, not only the answer.

Micro1-style interview

  • Keep full-stack, JS/TS, debugging, and verbal ownership stories.
  • Practice concise answers before adding depth.
  • Use the 25-minute mock block in Weeks 10–12.
